        03 / Data engineering

        From API to analytics

        The warehouse pipeline and the public dashboard share OpenWeather as their source.

        1. 01 / Extract

          OpenWeather + Airflow

          Airflow schedules requests for five cities every 30 minutes.

        2. 02 / Stage

          PostgreSQL

          Raw weather responses are stored as JSONB.

        3. 03 / Model

          dbt + Snowflake

          dbt builds city and date dimensions, plus weather readings and daily facts.

        Public dashboard: A separate GitHub Actions job fetches observations directly from OpenWeather and publishes the JSON snapshot used here.
